Status Firebase Cloud & Backup Database

Sinkronisasi Otomatis Aktif (Cloud Firestore)

Semua perubahan kegiatan, flyer, daftar hadir, materi, rekaman, dan template E-Sertifikat langsung tersimpan di Firebase dan otomatis tampil di halaman peserta tanpa perlu unggah ulang JSON ke GitHub.

Referensi Firestore Security Rules (Untuk Proyek Firebase Anda):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /settings/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /admin_users/{email} {
      allow read, write: if request.auth != null;
    }
    match /events/{eventId} {
      allow read: if true;
      allow write: if request.auth != null;
      match /attendees/{attId} {
        allow read, create: if true;
        allow update, delete: if request.auth != null;
      }
    }
  }
}
