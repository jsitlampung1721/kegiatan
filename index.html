Publikasi GitHub Pages & Sinkronisasi Data

Cara memublikasikan pembaruan data kegiatan ke seluruh peserta melalui repository GitHub Anda.

1. Export Database untuk GitHub

Karena GitHub Pages bersifat statis, setiap kali Anda menambah kegiatan, materi, atau merilis sertifikat di halaman Admin ini, klik tombol di bawah untuk mengunduh file data-kegiatan.json, lalu unggah (commit) file tersebut ke folder utama repository GitHub Anda bersama index.html dan admin.html.

2. Restore / Import Cadangan JSON

Punya file cadangan data-kegiatan.json dari perangkat lain? Unggah di sini untuk memulihkan seluruh data kegiatan dan daftar hadir.
